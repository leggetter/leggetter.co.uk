# Audio credits

Three samples used by the `classic` presentation package of the Dead Ball
penalty game. Everything else the game makes - the boot, the glove, the
woodwork, the save, the groan, the whistle - is synthesised at runtime and has
no source to credit.

This repository is public, so committing a sample redistributes it. Every file
here is **CC0 1.0 Universal (public domain dedication)**, which imposes no
attribution obligation. This file exists anyway: it is the record that each
licence was read before the file was committed, and it is what lets anyone else
check the same thing without taking it on trust.

All three were retrieved on **2026-09-19** from Freesound, from pages carrying
the CC0 dedication at the time of retrieval.

Each file was trimmed, converted to mono, filtered and re-encoded as mp3 from
the source's published preview. CC0 permits modification; the durations and
levels below describe the file in this directory, not the original.

## goal.mp3 — a crowd roaring a goal

- Source: https://freesound.org/s/25304/
- Author: `freesound` (Freesound.org user)
- Licence: CC0 1.0 Universal (public domain dedication)
