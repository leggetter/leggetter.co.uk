# Audio credits

Six samples used by the `classic` presentation package of the Dead Ball penalty
game. The glove, the woodwork and the referee's whistle are still synthesised
at runtime and have no source to credit.

This repository is public, so committing a sample redistributes it. Every file
here is **CC0 1.0 Universal (public domain dedication)**, which imposes no
attribution obligation. This file exists anyway: it is the record that each
licence was read before the file was committed, and it is what lets anyone else
check the same thing without taking it on trust.

All were retrieved on **2026-09-19** from Freesound, from pages carrying the CC0
dedication at the time of retrieval.

Four of the six come from one afternoon at one ground, recorded by one person
on one machine — the bed, the cheer, the save and the groan are the same crowd
heard at different moments, which is why they sit together rather than sounding
assembled.

Each file was cut from its source, converted to mono, filtered and re-encoded
as mp3. CC0 permits modification; the durations and levels below describe the
file in this directory, not the original.

## crowd.mp3 — the crowd bed, looped

- Source: https://freesound.org/s/494360/
- Author: `Sandermotions` (Freesound.org user)
- Licence: CC0 1.0 Universal (public domain dedication)
- Retrieved: 2026-09-19
- This copy: 11.0 s, mono, 44.1 kHz, 64 kbps
- Taken from: 0:24–0:36 of the source, a steady stretch of murmur with no
  event in it.
- Changes: high-passed at 70 Hz, level-flattened, loudness-normalised,
  downmixed to mono, and cross-faded end-to-start so it loops without a seam.
